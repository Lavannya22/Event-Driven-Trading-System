Key Design Decisions

Side Encoding — bit 16 of Event.type

The spec's 40-byte Event struct has no side field. Side (Bid/Ask) is packed into bit 16 of type, keeping the struct exactly 40 bytes and memcpy-safe.

type field layout:
  [15: 0]  EventType value (1–5)
  [16]     Side: 0 = Bid, 1 = Ask
  [31:17]  reserved (0)

STP via Participant ID in order_id

Self-trade prevention identifies participants without adding a struct field. Participant ID occupies the upper 16 bits of order_id:

order_id: [63:48] participant_id | [47:0] sequence
Participant 0 = anonymous (STP disabled)

CSV Format — Optional 7th Field

Extended the spec's 6-field CSV format with an optional side column (0=Bid, 1=Ask, default Bid):

timestamp,symbol_id,event_type,price,quantity,order_id[,side]

PostgreSQL Async Pattern

The engine hot path is never blocked by database I/O. All writes are enqueued to a background thread that drains to PostgreSQL via libpq. flush() uses a stack-allocated atomic<bool> sentinel — safe because the caller spin-waits before returning.

PriceLevel: vector → fixed array

// Before (Phase 1) — allocates on first push_back per level
struct PriceLevel {
    uint64_t             total_quantity{0};
    std::vector<uint64_t> order_ids;
};

// After (Phase 2) — no runtime allocation
struct PriceLevel {
    static constexpr std::size_t MAX_ORDERS = 16;
    uint64_t total_quantity{0};
    std::array<uint64_t, MAX_ORDERS> order_ids{};
    uint8_t count{0};
};

MatchOutput: vector → fixed array

// Before (Phase 1)
struct MatchOutput {
    MatchResult        result{MatchResult::Ok};
    std::vector<Event> events;  // allocates on fill
};

// After (Phase 2)
struct MatchOutput {
    static constexpr std::size_t MAX_EVENTS = 16;
    MatchResult result{MatchResult::Ok};
    std::array<Event, MAX_EVENTS> events{};
    std::size_t event_count{0};
    std::span<const Event> event_span() const noexcept;  // range-for compatible
};

Non-Obvious Engineering Notes

AllocationGuard — two build constraints

Static library problem: Linkers only extract object files from static libs when they resolve an explicit symbol reference. operator new replacements have no callers (they silently override the runtime), so they are silently omitted. Fix: compile AllocationGuard.cpp as a source file directly in the test executable.
Optimizer DCE problem: At -O2, Clang legally eliminates new T; delete p; sequences whose allocated value is never read (dead store elimination). This makes guard tests falsely show count = 0. Fix: target_compile_options(alloc_guard_tests PRIVATE -O0).

SignalRecord — not StrategySignal

The spec names the 32B pool-managed type StrategySignal, but that collides with enum class StrategySignal in Strategy.hpp. Renamed to SignalRecord to eliminate the ambiguity.

WSL2 detection

Both StartupValidator and ThreadAffinityManager detect WSL2 by scanning /proc/version for the string "microsoft". On WSL2: NUMA validation is skipped; thread affinity failures are warnings, not fatal errors.
